# Metas-Diarias



Aplicativo Android para ajudar no controle financeiro pessoal, organização de dívidas e acompanhamento de metas diárias.

O app foi pensado para facilitar o acompanhamento de gastos, obrigações e progresso financeiro de forma simples e visual.

## Funcionalidades

- Controle de metas diárias
- Registro e acompanhamento de dívidas
- Visualização do saldo e evolução financeira
- Organização de pagamentos e planejamento financeiro
- Interface simples, clara e voltada para uso rápido

# Tecnologias

- Kotlin
- Android SDK
- Jetpack Compose
- Material 3
- Gradle

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Diego-Andrade-hub/Metas-Diarias.git
```

2. Abra o projeto no Android Studio.

3. Sincronize o Gradle e aguarde a instalação das dependências.

4. Execute o app em um emulador ou dispositivo Android.

## Estrutura do projeto

O projeto está organizado como um aplicativo Android padrão, com a lógica principal e a interface do usuário em Kotlin.

## Objetivo

O objetivo do app é ajudar a manter melhor controle financeiro pessoal, priorizar pagamentos e acompanhar o progresso de metas no cotidiano.

## Observação

Este projeto foi desenvolvido como ferramenta prática para organização financeira e acompanhamento de dívidas pessoais.
